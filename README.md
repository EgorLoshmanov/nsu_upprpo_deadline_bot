# DeadlineBot

Telegram-бот для управления учебными заданиями и дедлайнами.

## Возможности

- **Предметы** — добавление, просмотр, редактирование, удаление
- **Задания** — пошаговый диалог, свободный ввод даты, заметки
- **Просмотр** — список активных, по предмету, ближайшие дедлайны, выполненные
- **Редактирование** — изменение любого поля задания или предмета
- **Автоматика** — утренние напоминания о завтрашних дедлайнах, автоочистка устаревших заданий
- **Персонализация** — каждый пользователь видит только свои данные

## Стек

- Python 3.12
- [aiogram](https://docs.aiogram.dev/) 3.x
- SQLite
- Docker

## Требования

- Python 3.12+ (для локального запуска)
- Docker и Docker Compose (для запуска в контейнере)
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather)

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/EgorLoshmanov/nsu_upprpo_deadline_bot.git
cd nsu_upprpo_deadline_bot
```

### 2. Создать файл `.env`

```bash
BOT_TOKEN=ваш_токен_от_BotFather
```

### 3a. Запуск локально

```bash
pip install -r requirements.txt
python bot.py
```

### 3b. Запуск через Docker

```bash
docker-compose up --build
```

Остановить:

```bash
docker-compose down
```

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Главное меню |
| `/add` | Добавить задание |
| `/list` | Список активных заданий |
| `/upcoming` | Ближайшие дедлайны (7 дней) |
| `/completed` | Выполненные задания |
| `/done` | Отметить задание выполненным |
| `/edit` | Редактировать задание |
| `/delete` | Удалить задание |
| `/subjects` | Управление предметами |
| `/cancel` | Отменить текущий диалог |
| `/help` | Справка |

## Форматы даты

При вводе дедлайна поддерживаются:

```
25.04
25.04.2026
25 апреля
завтра
послезавтра
```
